Sezione 1

Descrizione dell'Opera — QEN Framework

Il QEN Framework (Quantificazione Etica Naturale / Quantifying Ethical Network) è un sistema proprietario di scoring etico multi-dimensionale progettato per valutare operatori economici del settore HoReCa (Hotel, Ristoranti, Caffè), stabilimenti balneari e PMI artigianali rispetto a tre assi valoriali quantificabili.

L'opera è composta da: algoritmo matematico di scoring, motore di riconciliazione dati, sistema multi-agente LLM (Large Language Model), grafo semantico di conoscenza con 328 nodi, API REST documentata, modulo di compliance normativa EU AI Act/GDPR/CSRD, e interfaccia Copilot per analisi in tempo reale.

Sezione 2

Formula Matematica e Algoritmo di Scoring

2.1 Formula Standard (produzione)

QEN_score = (VS × 0.40) + (VA × 0.35) + (VT × 0.25)
VS, VA, VT ∈ [0, 100] · QEN_score ∈ [0, 100] · Soglia certificazione: ≥ 75

2.2 Formula Copilot API (endpoint pubblici)

QEN_score_copilot = (VS + VA + VT) / 3
Utilizzata negli endpoint /copilot-analyze e /gemini/qen-score per semplicità di integrazione

2.3 Normalizzazione automatica scala

if max(VS, VA, VT) <= 10:
    VS, VA, VT = VS * 10, VA * 10, VT * 10  # scala 0-10 → 0-100

# Il sistema accetta input in scala 0-10 o 0-100
# e normalizza automaticamente.

2.4 Formula con Motore di Riconciliazione (v2.0)

QEN_raw = VS×0.40 + VA×0.35 + VT×0.25
QEN_final = max(0, QEN_raw + Σ aggiustamenti_riconciliazione)
QEN_BASE_SCORE = 75 · Punteggio di partenza prima della riconciliazione

1. Architettura Logica — Workflow del Software

Il software deve operare come un "Filtro Deontologico" a quattro stadi:

  1. Ingestion — Acquisizione dati (Fatture fornitori, consumi energetici, certificazioni)
  2. Extraction (AI-OCR) — Identificazione dei parametri chiave (chilometraggio, tipo imballaggio, origine bio)
  3. Ethical Scoring (Il Motore QEN) — Applicazione della formula matematica ai dati estratti
  4. Compliance Output — Generazione del certificato "Green Claim UE" o blocco dell'azione per incoerenza etica

2. I 10 Parametri Fondamentali (KPI dell'Etica Naturale)

  1. Km-Zero Reale: Distanza tracciata tra produttore e sede HoReCa
  2. Indice di Imballaggio: % materiali riciclati/compostabili nel packaging
  3. Efficienza Risorse: Rapporto tra consumo idrico/elettrico e coperti serviti
  4. Certificazione Validata: Presenza marchi etici riconosciuti (Bio, FairTrade)
  5. Dignità del Lavoro: Rispetto parametri salariali e turni etici
  6. Biodiversità: Utilizzo varietà vegetali o razze animali non intensive
  7. Ciclo dei Rifiuti: % recupero e riduzione sprechi alimentari
  8. Trasparenza Documentale: Facilità accesso dati di filiera (Open Data)
  9. Impatto Sociale: Contributo dell'azienda alla comunità locale
  10. Integrità Digitale: Conformità GDPR, EU AI Act, sicurezza dati

3. Formula (pagina 2 del documento originale)

Score = (A × 0.40) + (B × 0.35) + (C × 0.25)
A = Compliance Legale (rispetto rigoroso Direttiva Green Claim UE)
B = Tracciabilità Operativa (dati oggettivi estratti dai flussi logistici)
C = Visione CVO (parametri discrezionali basati su Intelligence di Fuorimenu)

4. Specifiche per lo Sviluppo

  • Linguaggio: Python (analisi dati) con interfaccia React (Dashboard)
  • Database: Struttura non-relazionale per accogliere dati etici eterogenei
  • Requisito: Il sistema deve essere "Easy to personalize"

def qen_score(vs: float, va: float, vt: float) -> float:
    """Formula QEN standard: VS*0.40 + VA*0.35 + VT*0.25."""
    if max(vs, va, vt) <= QEN_SCALE_THRESHOLD:
        vs, va, vt = vs * QEN_SCALE_FACTOR, va * QEN_SCALE_FACTOR, vt * QEN_SCALE_FACTOR
    return round(vs * QEN_WEIGHT_VS + va * QEN_WEIGHT_VA + vt * QEN_WEIGHT_VT, 2)

def qen_score_copilot(vs: float, va: float, vt: float) -> float:
    """Formula Copilot API (media semplice): (VS + VA + VT) / 3."""

        vs, va, vt = vs * QEN_SCALE_FACTOR, va * QEN_SCALE_FACTOR, vt * QEN_SCALE_FACTOR

def _places_discover(key: str, settore: str, comune: str, max_results: int = 20) -> list:
    """Discover businesses via Google Places Text Search by settore and comune."""
    import sys
    templates = _PLACES_QUERIES.get(settore, [f"{settore} {comune}"])
    found: dict = {}
    for tpl in templates:
        q = tpl.format(comune=comune)
        try:
            resp = _requests.post(
                "https://places.googleapis.com/v1/places:searchText",
                headers={
                    "Content-Type": "application/json",
                    "X-Goog-Api-Key": key,
                    "X-Goog-FieldMask": (
                        "places.displayName,places.formattedAddress,"
                        "places.nationalPhoneNumber,places.websiteUri,"
                        "places.rating,places.userRatingCount,places.primaryType"
                    ),
                },
                json={"textQuery": q, "maxResultCount": min(max_results, 20)},
                timeout=8,
            ).json()
            for p in resp.get("places", []):
                name = p.get("displayName", {}).get("text", "")
                if not name or name in found:
                    continue
                found[name] = {
                    "name":    name,
                    "address": p.get("formattedAddress", ""),
                    "phone":   p.get("nationalPhoneNumber", ""),
                    "website": p.get("websiteUri", ""),
                    "rating":  p.get("rating"),
                    "reviews": p.get("userRatingCount"),
                    "type":    p.get("primaryType", ""),
                    "settore": settore,
                    "comune":  comune,
                }
                if len(found) >= max_results:
                    break
        except Exception as e:
            print(f"[Places] discover exception: {e}", file=sys.stderr)
        if len(found) >= max_results:
            break
    return list(found.values())

def _extract_json(raw):

    @classmethod
    def load_from_env_file(cls, env_file_path: str = ".env"):
        if os.path.exists(env_file_path):
            load_dotenv(env_file_path)
        else:
            print(f"⚠️  .env file not found at {env_file_path}")

    @classmethod
    def validate(cls) -> bool:
        required = [
            ("ANTHROPIC_API_KEY", "Claude API"),
            ("MISTRAL_API_KEY",   "Mistral API"),
            ("NEO4J_PASSWORD",    "Neo4j Password"),
        ]
        missing = []
        for key, name in required:
            value = os.getenv(key, "")
            if not value or value.startswith("[") or value == "PLACEHOLDER":
                missing.append(f"{name} ({key})")
        if missing:
            print("❌ MISSING CREDENTIALS:")
            for item in missing:
                print(f"   - {item}")
            return False
        print("✅ All credentials present")
        return True
