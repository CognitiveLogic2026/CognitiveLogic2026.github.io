Accessibility Statement

Last updated: July 2026 · Version 1.0

Cognitive Logic is committed to making its website accessible, in line with the principles of the Web Content Accessibility Guidelines (WCAG) 2.1, level AA, and in the spirit of EU Directive 2016/2102 (Web Accessibility Directive) and EU Directive 2019/882 (European Accessibility Act). cognitivelogic.it does not fall within the mandatory scope of these regulations (which cover public-sector bodies and, for the EAA, specific categories of private products/services), but this statement is published voluntarily, in line with the QEN project's commitment to its Social Value dimension.

1. Conformance status

This site is partially conformant with WCAG 2.1 AA. "Partially conformant" means that some parts of the content do not yet fully conform to the accessibility standard, as listed in section 2.

2. Non-accessible content

As of this statement, the following limitations are known:

  • Some interactive data visualisations (the Knowledge Graph in qen-live.html) do not offer a complete text alternative equivalent to the visual content, beyond a link to the Operators Directory in list/table format
  • Some tool pages (auditors, widgets, generators) use custom interactive components that may not be fully optimised for advanced assistive technology use (screen readers on complex interactions, voice dictation)
  • Some historical documents in static HTML or PDF format (e.g. technical dossiers) have not been individually verified for WCAG conformance

3. Measures taken

  • Colour contrast programmatically verified across the site's navy/gold palette (ratios ≥ 4.5:1 on all main text/background combinations)
  • Semantic heading structure (a single H1 per page, consistent H2/H3 hierarchy)
  • A "Skip to content" link present on all main pages for keyboard navigation
  • Visible keyboard focus indicators on links, buttons and form fields
  • Text labels (aria-label) on SVG visualisations where the equivalent numeric data is also reported in text/table form

4. Feedback

If you encounter accessibility barriers while using the site, please report it to info@cognitivelogic.it, indicating the page affected and the assistive technology used. We aim to respond within 30 days.

5. Preparation of this statement

This statement was prepared on 10 July 2026 based on an internal self-assessment, not an external certified audit.
