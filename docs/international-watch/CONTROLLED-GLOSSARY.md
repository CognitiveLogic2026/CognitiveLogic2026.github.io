# Glossario controllato

| Termine | Definizione vincolante |
|---|---|
| Monitoring case / dossier | Contenitore governato di uno o più eventi, claim, snapshot e assessment; non è un evento né una conclusione. |
| Evento | Occorrenza delimitata per tempo, luogo e attori alla quale sono riferiti claim. |
| Sotto-evento | Parte temporalmente o causalmente delimitata di un evento padre. |
| Snapshot temporale | Vista versionata del dossier a uno specifico `as_of`; non generalizzabile oltre tale istante. |
| Claim | Proposizione atomica testabile o qualificata, con origine, scope e tempo. |
| Fonte | Soggetto o canale da cui si accede a un contenuto; non coincide necessariamente con l'originatore. |
| Documento | Artefatto delimitato e versionabile che veicola uno o più claim. |
| Evidenza | Elemento osservabile collegato a uno specifico claim, capace di sostenerlo, contraddirlo o limitarlo. |
| Affermazione sull'evidenza | Descrizione o interpretazione di ciò che un'evidenza mostrerebbe; resta distinta dall'evidenza. |
| Origine dell'affermazione | Primo soggetto/documento identificabile che formula il claim nella catena ricostruita. |
| Ripubblicazione | Riproduzione sostanziale di contenuto altrui; non è conferma indipendente. |
| Traduzione | Trasformazione linguistica dichiarata; non crea nuova origine o evidenza. |
| Sintesi | Riduzione selettiva di contenuto; deve rendere visibili omissioni e perdita di contesto. |
| Inferenza analitica | Conclusione derivata tramite regola esplicita; non è osservazione. |
| Fatto osservabile | Claim riferito a una proprietà direttamente osservabile secondo un metodo dichiarato. |
| Dichiarazione | Claim che attesta che un soggetto ha detto o dichiarato qualcosa; non attesta automaticamente il contenuto. |
| Inferenza | Claim derivato da evidenze mediante passaggi espliciti. |
| Interpretazione | Attribuzione contestuale di significato, distinta da osservazione e inferenza formale. |
| Corroborazione | Convergenza claim-specifica di evidenze con origini/raccolte sufficientemente indipendenti. |
| Contraddizione | Incompatibilità tra proposizioni comparabili per definizioni, scope e tempo. |
| Fisicamente navigabile | Condizione fisica locale che consente il transito a una classe definita di mezzi in un tempo definito. |
| Formalmente dichiarato aperto | Stato dichiarato da un'autorità identificata; non prova libertà o praticabilità effettiva. |
| Normale libertà commerciale di navigazione | Possibilità ordinaria e non eccezionale di transito commerciale, distinta dalla mera praticabilità. |
| Controllo operativo | Capacità effettivamente esercitata di dirigere o limitare operazioni in un'area/tempo. |
| Capacità di interdizione | Mezzi plausibilmente disponibili per impedire attività; non prova esercizio o controllo. |
| Controllo amministrativo | Esercizio di funzioni amministrative; non equivale necessariamente a controllo operativo o sovranità. |
| Controllo giuridico | Competenza giuridica riconosciuta entro un quadro definito; distinta dall'effettività materiale. |
| Sovranità | Titolo/autorità suprema rivendicata o riconosciuta secondo il diritto applicabile; non deducibile dai soli controlli precedenti. |
