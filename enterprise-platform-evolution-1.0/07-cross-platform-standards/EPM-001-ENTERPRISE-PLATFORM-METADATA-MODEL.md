# EPM-001 — Enterprise Platform Metadata Model

Status: PROPOSED
Implementation Authorized: NO

## Core Metadata

- identifier
- asset_type
- title
- author
- owner
- publication_date
- last_update
- language
- canonical_url
- topics
- entities
- source_reference
- governance_state
- lifecycle_state
- related_assets

## Principles

- One asset, one identifier.
- Explicit metadata.
- Traceable sources.
- Stable identifiers.
- Semantic consistency.

## Constraints

- Nessuna implementazione.
- Nessuna modifica al sito.
- Nessun commit.
- Nessun push.
