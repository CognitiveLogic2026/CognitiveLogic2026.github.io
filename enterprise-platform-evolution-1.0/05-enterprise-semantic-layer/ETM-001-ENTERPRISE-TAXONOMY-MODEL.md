# ETM-001 — Enterprise Taxonomy Model

Status: PROPOSED
Implementation Authorized: NO

## Purpose

Definire il sistema di classificazione comune della Cognitive Logic Enterprise Platform.

## Taxonomy Principles

- Classificazioni semplici e governabili.
- Separazione tra dominio, tipo, tema e settore.
- Vocabolario controllato.
- Riduzione di sinonimi e duplicazioni.
- Compatibilità multilingue.
- Estensione progressiva.
- Nessuna categoria priva di definizione.
