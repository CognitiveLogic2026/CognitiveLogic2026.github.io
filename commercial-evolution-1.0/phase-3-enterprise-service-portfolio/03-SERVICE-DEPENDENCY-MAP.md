# Service Dependency Map

Status: APPROVED

## Primary sequence

Executive Discovery
↓
Governance Vision Workshop
↓
Assessment
↓
Architecture
↓
Implementation
↓
Governance
↓
Continuous Governance

## Foundation precedes Assessment

I servizi Foundation definiscono:

- perimetro
- stakeholder
- obiettivi
- priorità
- contesto operativo

## Assessment precedes Architecture

Gli Assessment producono le evidenze necessarie per progettare:

- target architecture
- operating model
- governance roadmap
- KPI
- controlli

## Architecture precedes Implementation

L'Implementation non deve iniziare senza:

- stato corrente documentato
- target state approvato
- responsabilità definite
- dipendenze conosciute
- roadmap validata

## Governance follows Implementation

La Governance verifica:

- adozione
- efficacia
- conformità
- qualità delle evidenze
- maturità

## Continuous Governance

I servizi continuativi mantengono e aggiornano:

- KPI
- policy
- assessment
- intelligence normativa
- executive reporting
- roadmap evolutiva
