# Enterprise Service Portfolio

Status: APPROVED

## Architectural decision

Cognitive Logic adotta un portafoglio modulare organizzato secondo il livello
di maturità del cliente.

Il portafoglio non costituisce un semplice elenco di consulenze.

Costituisce un percorso progressivo di trasformazione:

1. Foundation
2. Assessment
3. Architecture
4. Implementation
5. Governance
6. Continuous Governance

- Executive Discovery
- Governance Vision Workshop
- AI Governance Orientation
- Knowledge Discovery
